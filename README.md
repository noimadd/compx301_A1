## AI usage overview
AI was used in developing the method in order to solve the problem/s. I would suggest potential ideas and have it tell me whether the idea was good or not
alongside an explanation and if it had any better ideas that I should look to use instead. This way I could have a general idea(not pseudo code) of the way 
in which I wanted to go about approaching the problem, something I would do with or without the assisstance of AI, but was streamlined with the use of it as 
it allowed me to quickly research a variety of different methods(e.g. array vs hashmap for the lookup tables) and it prevented me from going down unecessary 
rabbit holes.
<br>
I would also use it when I had been stuck on a specific bug for an extended period of time. A great example of this was when I was developing the strAdd 
method I had an issue where 9999 + 11 = 9900 after being unable to solve this and asking an AI model it pointed out that when I was doing my carry I was 
only ever checking using my sum variable, so when my value that added the previous carry created a value with a carry this was not checked and it was ignored.
